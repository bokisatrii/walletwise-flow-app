# WalletWise

**WalletWise** is a personal finance web app for tracking income and expenses, managing recurring subscriptions and getting a visual overview of your spending. It is a mobile-first single-page app built with React, TypeScript and Supabase.

> Originally scaffolded with [Lovable](https://lovable.dev); the repo can still be edited in Lovable or locally.

## Features

- **Authentication** – email/password sign up and sign in via Supabase Auth; all app routes are protected.
- **Dashboard** – balance overview, spending charts and recent transactions.
- **Transactions** – add, edit and delete income/expense entries with category, subcategory, description, date and currency.
- **Subscriptions** – track recurring payments (monthly or yearly), see them on a payment calendar, and get a toast reminder the day before a payment is due (dismissible).
- **Insights** – spending trends and category breakdown charts. The "AI Insights" cards are currently placeholder/mock content; the "Generate" button is not wired to an AI service yet.
- **Multi-currency** – EUR, USD and RSD. Amounts are stored in their original currency and converted for display using live rates from `exchangerate-api.com` (with hard-coded fallback rates). The chosen display currency is remembered in `localStorage`.
- **Charts** – pie/category charts, daily spending chart, legends and tooltips built with Recharts.
- **Mobile navigation** – bottom navigation bar layout.

Transaction categories: Food & Dining, Transportation, Shopping, Entertainment, Bills & Utilities, Healthcare, Education, Travel, Other.

## Getting started

Requirements: **Node.js 18+** and npm (a `bun.lockb` is also included if you prefer Bun).

```bash
git clone https://github.com/bokisatrii/walletwise-flow-app.git
cd walletwise-flow-app
npm install
npm run dev
```

The dev server runs at <http://localhost:8080>.

## Backend (Supabase)

The app talks directly to Supabase from the browser. The client is configured in `src/integrations/supabase/client.ts` (generated by Lovable) with the project URL and the public anon key.

To use your own Supabase project, update the URL and anon key in that file, then apply the SQL in `supabase/migrations/` and set `project_id` in `supabase/config.toml`.

Main tables (see `src/integrations/supabase/types.ts`):

- `transactions` – `amount`, `type`, `category`, `subcategory`, `description`, `date`, `currency`, `user_id`
- `subscriptions` – `name`, `amount`, `currency`, `renewal_interval`, `next_payment_date`, `description`, `user_id`

> The migrations in this repo are incremental changes (currency and subcategory columns, cleanup, function hardening). They do not include the initial table creation or Row Level Security policies, so make sure both are set up in your Supabase project so users can only access their own rows.

## Project structure

```
├── public/                     # Static assets (favicon, robots.txt)
├── src/
│   ├── components/             # App components (forms, modals, charts, layout, navigation)
│   │   └── ui/                 # shadcn/ui components
│   ├── config/routes.tsx       # Route definitions

│   ├── lib/                    # Utilities and chart helpers
│   ├── pages/                  # Auth, Dashboard, Transactions, Subscriptions, Insights, NotFound

│   ├── App.tsx
│   └── main.tsx

├── components.json             # shadcn/ui configuration
├── tailwind.config.ts
```

## Deployment

The app is a static SPA. Run `npm run build` and deploy the `dist/` folder to any static host (Vercel, Netlify, Cloudflare Pages, etc.), making sure all routes fall back to `index.html`. Alternatively, publish it from Lovable via **Share → Publish**.
